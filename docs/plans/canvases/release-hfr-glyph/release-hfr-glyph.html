Release (HFR) icon

Release (HFR) moves from the menu header into the quick-command strip, first in the row while the departure is held for release. It needs an icon. Each lane shows a held departure's strip with Release (HFR) first (dashed outline), then Check release window (the existing clock), Taxi to runway, Hold position and Cleared for takeoff. The header line shows what pointing at the new icon would say. Family colour: grey-white, like Check release window.
