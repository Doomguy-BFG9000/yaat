YAAT-545 · aircraft context menu · the label row above the icon strip

Quick-command label

The settled design removes the reserved label row. Pointing at or focusing an icon replaces the header's state line with name — command on one line, scrolling as a marquee when it overflows, and the tooltip goes. Three choices are still open.

Every lane is a live copy of the menu. Point at the icons yourself (Tab reaches them too), or watch the dashed replay cursor, which takes the same path through every lane of a section at the same moment. A lane hands the cursor back about two seconds after you leave it.

Choice 1 · timing

When the label comes and goes

Moving from one icon to the next never leaves the strip: the 6 px gaps belong to the strip's own menu item, so every lane swaps labels at once between icons. The timing only matters when the pointer leaves the strip.

Choice 1, continued · marquee

How fast the long label scrolls

The longest label a strip icon carries today is Reduce to final approach speed - 145 kt with its command RFAS. The line waits 800 ms, scrolls until the end is in view, waits 800 ms and scrolls back. The top specimen is the menu as it stands; the lower one is the menu at its narrowest once the 224 px label panel no longer pins its width and the five-icon row sets it.

Choice 2 · the point menu

Where the label goes when there is no state line

A taxi-node point menu opens with its title and goes straight to the strip. Lanes A and B use the same 23 px line the state line has on the aircraft menu.

Choice 3 · the flyout cue

Telling an icon that opens a flyout from one that sends

Today the label row says "Exit left ›" over "opens a submenu", and a 6 px triangle notch sits in the icon's corner. One line leaves no room for "opens a submenu". Exit left and Exit right open flyouts here; Cleared to land sends CLAND.

How the mock is built, and what it leaves out

  • Sizes come from the code and from docs/releases/img/whats-new-quick-commands.png: a 290 px menu on #2B2B2B, 25 px rows, 23 px state line, 42 px buttons (40 px cell and its border) 6 px apart, 52 px label panel plus 6 px spacing. That shot is an older build, so the well and glyph colours follow the current QuickCommandStrip (#1F2226 wells, FamilyColor) instead.
  • Sections 1 and 2 use cue B (" ›") and the 30 px/s marquee, so each section differs only in what it tests. The label is drawn at 12 px, the name light and the command in JetBrains Mono, where the state line stays 11 px grey.
  • Inter and JetBrains Mono load from Google Fonts; Avalonia's text rendering and hinting differ a little, so an overflow measured here can be a few pixels off the app's.
  • The aircraft menu stops after Delete (the RPO items and Settings for this view… are left out), flyouts do not open, the latched icon state is not drawn, and arrow-key navigation is not reproduced. The 145 kt in the long label is illustrative.
  • In lane 2A the real menu would re-lay out every frame while the pointer sits on the band that moves; the mock waits 150 ms between flips so the loop can be seen.
